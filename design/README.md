# ViFastKey design tokens

Nguồn duy nhất cho màu, font, spacing và radius. Các UI map token sang:

- `web/style.css` — landing page + playground
- desktop/mobile/extension (khi có) — dùng cùng palette, thứ tự nút và trạng thái

Quy ước: nền kem sáng, accent đỏ logo, vàng cho điểm nhấn, font Be Vietnam Pro.
Không cần giống pixel tuyệt đối giữa các nền tảng, nhưng phải cùng palette và hierarchy.

Logo và mã màu gốc nằm ở `resources/brand/README.md`.
